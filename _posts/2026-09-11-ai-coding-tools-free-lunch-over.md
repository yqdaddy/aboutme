# AI 编程工具的免费午餐，终于结束了

> "开源公司的股价，和 API 的稳定性，大约是两件事罢。"

前几天，我朋友圈里有人发了一截图——Copilot 的用量账单，一个月两千多块。

他问我怎么这么贵。

我说，你用的是 Claude Opus 啊，那个每次调用消耗的 token 数，是 GPT-4o-mini 的二十七倍——不对，准确说是二十七倍，我刚才记混了，实际是约 27 倍。

他没说话。

大概三周前，GitHub 宣布 Copilot 改收费模式。Anthropic 也限了 Claude Code 里 Opus 的访问权限。

我看完第一反应不是"这正常"。

是"烦死了"。

说实话，这反应有点悲观——但我的直觉从来没骗过我。

---

## 表面上：AI 编程工具终于"成熟"了

媒体写得热闹。

"告别订阅制，拥抱按量计费"、"让定价更公平"、"为可持续发展买单"——标题一个比一个昂扬。

数据也确实"合理"：Copilot 从 6 月 1 日起，按 AI Credits 计费；Claude Code 的 Pro 用户，想用 Opus 得额外付费。

看着看着，我差点信了。

但我还不料，也不信竟会到这地步。

恶心的是这种"先涨再降"的套路——其实也不能全怪资本，商业嘛，都这德行。但开发者被当猴耍的感觉，实在不好受。

8 月之前，我认识的做产品的朋友，底层清一色接的 Claude。为什么？便宜。

那时候 Claude Code 的 API 价格，大概是 OpenAI 的十分之一。这差距，足以让任何成本敏感的开发者抛弃尊严。

横竖都是它说了算。你用户？用户算个屁。

---

## 深层看：免费的账，资本不认

我翻开 AI 编程工具的定价页一查，这历史没有年代，歪歪斜斜的每页上都写着"无限畅饮"几个字。

我横竖睡不着，仔细看了半夜，才从字缝里看出字来，满本都写着两个字——"亏钱"。

说真的，这太扯了。

Copilot 不是第一家。Cursor、Windsurf、GitHub Copilot——谁不是烧钱烧出来的用户？

免费意味着什么？

意味着你可以白嫖。

API 用户的逻辑很简单：既然订阅费固定，我用多少都是一个价，为什么不多用？

答案有两个：一是幻觉——你以为你在用"辅助工具"，其实你在用"替代工具"；二是惯性——一旦习惯了对AI说"帮我重构这个模块"，你就停不下来。

但资本市场不这么看。

你免费了三年，现在告诉我你要"可持续发展"？

估值逻辑是什么？是用户量。是活跃度。是"AI 时代的基础设施"的故事。而这些，都需要钱来撑。

研发要钱。GPU 要钱。上市要钱。

钱从哪来？

涨价。

涨了之后用户骂——骂得很难听，Twitter 上直接炸了。炸得我看着都心疼。虽然我不是 Copilot 员工，但作为开发者，这种场面实在令人绝望。

骂了之后怎么办？

财报之前得把收入做漂亮，所以又降了额度。

横竖都是它说了算。你用户？用户算个屁。

---

## 对开发者意味着什么？

说真的，这挺让人绝望的。

我认识几个做 AI 应用的朋友，底层清一色接的 Claude。为什么？便宜。

但现在情况不太对。

其一，价格波动太剧烈。Copilot 改了计费模式，月度账单从"固定 $19"变成"浮动数百"，这种过山车——你敢把生产环境绑在上面？反正我不敢。我有个朋友上周刚迁移了一半流量到豆包，这周又开始犹豫要不要迁回来。这种反复横跳，累不累？

<!-- ✏️ 编辑建议：在这里加一句你见过的类似"变脸"案例 -->

其二，升级即陷阱。

以前以为买了 Pro 就是"无限用"，结果发现 Pro 也有额度限制。额度用完就降级，降级就慢，慢了就不想用。

这套路——说是"按需付费"，其实是"按心付钱"。不对，更准确地说，是"按焦虑付钱"。

其三，选型焦虑来了。

Cursor 涨价，Copilot 改计费，Claude Code 限 Opus，GitHub Copilot 用新计费模型——每个都在变，每个都在"优化"。

你说选哪个？

大概没标准答案。

---

## 我的判断

如果你是 AI 编程工具的用户，现在该做什么？

第一，别把所有鸡蛋放一个篮子。接入多个工具，至少准备好备选方案。Cursor、Claude Code、Windsurf、Copilot——谁都能用，换掉一个的迁移成本没那么高。这话我说了三遍，大约还是有人不信。

第二，关注账单周期。每季度看一眼用量和费用变化。财报压力大的时候，往往是"优化政策"的时候。

第三，如果你跑得动本地部署——开源的模型终究是开源的。虽然显卡贵，但至少不会被涨价背刺。被显卡价格背刺，总比被 API 价格背刺好——至少显卡还在你手里。

说来说去，还是一句话：

**AI 编程工具的免费午餐，终于结束了。**

大抵如此。

# 别再刷几十个 APP 找选题了：我写了个 ClaudeCode Skill，一句话查 50+ 平台热点

> "信息洪流里，大抵每个做内容的人，都在做着同一件蠢事。"

我向来是不惮以最坏的恶意来推测"碎片化阅读"的。

每天早上睁眼，第一件事是刷微博热搜。

第二件事是刷知乎热榜。第三件事是刷 36 氪早报。第四件事是刷 B 站热门。

刷完一圈，一小时过去了。热点没抓到几个，焦虑倒是攒了一箩筐。

我横竖睡不着，仔细看了半夜这些 APP，才从字缝里看出字来。

满本都写着两个字——**重复**。这哪里是获取信息？分明是信息在消费你。

这条新闻你在微博看过，在知乎又刷到了，在头条又推了一遍。你把时间浪费在"刷"上，而不是"写"上。

大抵每个做内容的人，都要经历这个阶段的。别急，慢慢来。但经历了之后，你就该找个工具了。

## 一、信息洪流里的"西西弗斯"

说一个真实的场景。

我自己的公众号，主打 AI 编程和工程化落地。关注我的读者都知道，5 月份我写了一篇《国产 AI 编程工具 5 月大洗牌：通义限免要结束了，Trae 又偷偷更新了》，跑了 **5,651 阅读**，28 条评论。

但你知道这篇选题是怎么来的吗？

我当时为了找这个选题，需要打开：微博、知乎、B 站、36 氪、虎嗅、少数派、IT 之家、GitHub Trending、掘金、CSDN、V2EX、豆瓣……

十几个平台，挨个刷一遍，光是打开关闭标签页，手就酸了。

更要命的是，这些平台的热点，80% 跟 AI 编程无关。微博热搜 Top50 里，3 条跟科技沾边。知乎热榜 Top 10 里，全是娱乐八卦。

我花了一小时，筛出了 1 条能用的选题——就是后来 5651 阅读的那篇。

**这哪里是追热点？这分明是在垃圾堆里淘金。更可悲的是，你每天都在做同样的事，却从不去想为什么要做。**

## 二、程序员的"终极倔强"：没有好轮子，就自己造一个

既然没有现成的工具，那就自己造。

这是我的开源项目 **DailyHot Skill**——一个 Claude Code 的 Skill 扩展，一句话查询 **56+ 个中文内容平台**的热搜/热榜数据。

**它能干什么？**

1. **单平台极速查询**：你对 Claude Code 说一句"看看微博热搜"，它就能列出实时 Top 10。
2. **跨平台 AI 聚合**：你不需要挨个平台刷。对它说"帮我整理今天 AI 编程相关的所有热点"，它会同时去查 36 氪、知乎、B 站、GitHub、掘金等平台，帮你筛出跟 AI 编程有关的内容，合并成一个报告。
3. **零学习成本**：不需要记命令，不需要学语法。用自然语言说你要什么，它就给你什么。

**技术架构其实很简单：**

```text
你说话 → Claude Code → DailyHot Skill → localhost:6688 (本地服务) → DailyHot API (56+ 平台)
```

底层接入了开源的 DailyHot API（MIT 协议），聚合了 56 个平台的数据。我把它封装成了 Claude Code 的 Skill，让 AI 能听懂你的需求。

## 四、如何安装？


**方式一：发给你的 Claude Agent 自动安装（通过 SkillHub CLI）**

已在 SkillHub 上架审核通过。复制下面这段话，发给你的 Claude Agent：

```text
请先检查是否已安装 SkillHub 商店，若未安装，
请根据 https://skillhub.cn/install/skillhub.md 安装SkillHub商店，
但是只安装CLI，然后安装dailyhot-skill技能。
若已安装，则直接安装dailyhot-skill技能。
```

Agent 会帮你自动完成安装和配置。

**方式二：一行命令，全局安装**

```bash
npx skills add yqdaddy/dailyhot-skill --skill dailyhot-skill -a claude-code -g
```

**安装依赖并启动服务**：

```bash
cd ~/.claude/skills/dailyhot-skill
npm install && node scripts/start-server.mjs
```

服务启动后，打开 Claude Code，直接说"看看今天的热点"，它就知道你要什么。

**支持 56+ 个平台**，涵盖综合新闻、科技互联网、媒体社区、地震预警等类别。

完整使用文档与平台列表：
- **SkillHub**：https://skillhub.cn/skills/dailyhot-skill
- **GitHub**：https://github.com/yqdaddy/dailyhot-skill

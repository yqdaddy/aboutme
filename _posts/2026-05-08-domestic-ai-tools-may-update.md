# 国产AI编程工具5月大洗牌：通义限免要结束了，Trae又偷偷更新了

> "工具选错了，效率不升反降。"

上个月我横评了三家国产AI编程工具——通义灵码、CodeGeeX、文心快码。发完之后，评论区比文章还热闹。

有人问我：通义限免到期怎么办？Trae SOLO 出来了要不要换？Cursor 3 值不值得买？

行，今天更新一期。不废话，只看这一个月的变化。

---

## 一、通义灵码：限免倒计时，薅羊毛最后窗口

**最大的事**：个人专业版限免到 2026 年 5 月 30 日 18:00 结束。

还有不到一个月。到期后自动退回基础版——隐性限流 2 万 token/天，@workspace 工程分析功能降级，Agent 能力进一步砍。

也就是说，上个月我推荐的"通义灵码 Java 开发者必装"，下个月开始就得花 ¥59/月了。

**好消息是**：通义灵码刚上线了 AI IDE（独立客户端），不再只是 VS Code/JetBrains 插件。支持长期记忆、行间建议预测、行间会话——这些在插件版里要么没有，要么体验打折。

**我的判断**：如果你主用 Java/Spring Boot，趁限免最后这二十天，把 AI IDE 装上，把项目上下文喂进去。到期后基础版虽然砍了功能，但长期记忆是保留的——这才是核心价值。

---

## 二、CodeGeeX：涨价后的"补偿期"，还能用吗

上个月 CodeGeeX 涨价 30% 的事闹得沸沸扬扬。智谱发了致歉信，给了补偿方案。

这个月观察下来：**模型确实弱了一截**。不是错觉——同样的 Java 转 Python 任务，上个月能直接跑通的代码，这个月生成的缺了依赖声明。多线程场景更是直接摆烂。

**但有个细节很多人没注意**：CodeGeeX 的免费基础版没涨价，代码补全、注释生成依然不限次。涨价的是 Pro 版（~$20/月），而 90% 的用户其实只用基础功能。

**我的判断**：学生党和轻量用户继续白嫖没问题。重度用户？建议换通义灵码+CodeGeeX 双开——一个写核心逻辑，一个补其他语言。

---

## 三、文心快码：悄悄改了定价页面

上个月我吐槽文心快码的"土味收费"——50 次免费额度、密密麻麻的定价表。

这个月去看，**定价页面确实改版了**：简洁了不少，去掉了部分隐藏收费项。但核心问题没变——高级功能（多轮对话、代码重构）依然要额外买次数包，18 元/50 次到 150 元/500 次。

**但 C++ 能力确实没对手**。IDC 评分不是吹的，底层开发场景文心快码生成的代码，编译通过率比其他家高出一截。

**我的判断**：C++ 开发者没得选，只能用它。但建议只在写 C++ 时开，其他语言切通义灵码——省钱。

---

## 四、国产之外：Trae 和 Cursor 的新动作

**Trae SOLO**：字节跳动的端到端自动化模式，PRD→架构→编码全自动。还在内测，但看演示视频，完成度比通义灵码的 Agent 高一个档次。

**Cursor 3**：代号 Glass，界面大改。多 Agent 并行、云端执行、跨仓库协作——一句话概括：从"编辑器"变成了"工作台"。$20/月的 Pro 版现在能跑 8 个 Agent 同时干活。

**我的判断**：Trae SOLO 公测后，国产工具的竞争格局会重新洗牌。Cursor 3 的多 Agent 并行确实惊艳，但 $20/月对国内开发者来说还是贵。

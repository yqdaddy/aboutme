# 别再@你的 Agent 了——港大刚开源了 AgentSpace，给它造个工位

> "Agent 的本质不是被调用的工具，是可以一起工作的队友。"
>
> "以前用 Agent，像是在用一个随时会消失的临时工；现在才算是给团队招了正式员工。"

**香港大学数据智能实验室（HKUDS）开源了 AgentSpace。**

这和 LightRAG 是同一个实验室出的。我向来是不惮以最坏的恶意来推测"AI Agent 新框架"的，大抵不过是换了个更大的底座，或者多塞几个无关痛痒的 Agent，继续割韭菜。

说实话，看腻了。

然而这次，看着 GitHub 上的项目描述——"Human + Agents. One Team. One Workspace"——我横竖睡不着，仔细看了半夜，才从字缝里看出字来。

满本都写着两个字——**治理**。

这背后，大抵是 Agent 技术从个人玩具向团队协作迈进的分水岭。别再一个人终端里@来@去了——累不累啊？AgentSpace 的这次开源，给 AI 工程化上了一堂生动的课。

---

## 一、从工具到队友：Agent 终于有工位了

以前的 Agent，大抵是个临时工——说难听点，连临时工都算不上。

你@它，它干活；你关掉终端，它消失。下次再@，之前的上下文全没了——像是每次都要重新面试一遍。烦死了。更扯的是，一个团队里七八个人各自用各自的 Agent，谁也不知道别人的 Agent 干了什么。

这就是 Agent 工程化里最大的痛点——**Agent 没有组织身份，永远是散兵游勇。**

AgentSpace 干了件大事：**把 Agent 定义成了"数字员工"。**

这意味着什么？意味着每个 Agent 有自己的角色、权限、日程，甚至可以和其他 Agent 协作。不是你@它它才动，而是它可以被分配任务、追踪进度、记录产出。文档里直接对比了飞书——飞书是人类协作的，AgentSpace 是人类和 Agent 一起协作的。

终于有人想明白这事儿了。

它不再是临时工，而是真正进了编制。

**工程启示**：
> **Agent 不该是工具，是团队成员。**
> 当你的老板问你"这几个 Agent 谁在用、干了什么"时，AgentSpace 就是你的答案。它把散落在个人终端的对话，变成了可治理的团队资产。

---

## 二、权限治理：从一群野蛮人到组织架构

很多团队用 Agent，是一个人一个终端，各干各的。

说实话这事儿挺扯的。

又当爹又当妈：既要负责分配任务，又要负责追踪进度，还要负责审计记录。结果就是谁也不知道谁干了什么，出了问题根本追溯不到。更可怕的是，Agent 可能访问了不该访问的数据——你根本控制不了。

这事儿简直绝望。

AgentSpace 搞了个**多维度权限治理体系**。

它把 Agent 嵌入了组织架构：

* **角色定义**：每个 Agent 有明确的岗位描述和 owner，比如"数据分析师"、"代码审查员"
* **权限分配**：Workspace 角色、频道访问、文档权限、Runtime 授权，分门别类
* **审计追踪**：每个操作都有记录，谁授权的、什么时候干的、结果如何

甚至还有审批流——高风险动作（文档访问、工具调用、外发动作）会自动进入人类审批节点。

术业有专攻。这哪里是技术升级？这分明是 HR 的胜利。

用权限体系管住 Agent，用审计记录追踪产出。工程启示很明确：

> **失控的 Agent 比没有 Agent 更可怕。**
> 以前我们迷信 Agent 能省人力，现在 AgentSpace 告诉我们：治理，才是规模化的前提。不然就是裸奔——看着省事，出事就完了。

---

## 三、工作流协同：从散落对话到协作空间

Agent 圈有句名言：**Garbage In, Garbage Out.**

但更可怕的是——对话散落，根本没人知道发生过什么。这就不只是垃圾进垃圾出了，是垃圾进去、然后烂在系统里。

AgentSpace 在工作流上动了不少刀子。

**1. 任务调度系统**
不再是随时@随时干。Agent 可以被分配定时任务、周期性工作，甚至可以在日程表上看到它的排期。这意味着你可以把一个长期运行的 Agent 放在那里，它自己会按时干活。

**2. 能力共享**
一个 Agent 会的东西，可以共享给其他 Agent。不再是每个 Agent 从头学起，而是可以在团队内部沉淀和复用能力。

**3. 多 Agent 协作**
复杂任务可以拆解给多个 Agent，它们之间可以传递信息、分工协作。就像一个真正的团队。

**工程启示**：
> **协作空间是 Agent 规模化的基础设施。**
> 没有协作空间，Agent 永远是散兵游勇——不对，应该说，永远是"不可控的黑盒"。AgentSpace 明白这个道理，所以它把工位建好了。

---

## 四、结语：从玩具到生产力

AgentSpace v1.0 的开源，不仅仅是几个功能的叠加。

它释放了一个信号：Agent 已经过了个人尝鲜的阶段，开始真正解决团队协作的难题。说实话，这点挺让人意外——我一直觉得 Agent 框架都在卷参数，没想到有人开始卷治理了。

* 数字员工身份解决了散兵游勇的问题。
* 权限治理解决了失控和追溯的问题。
* 工作流协同解决了对话散落的问题。

HKUDS 团队——就是那个做 LightRAG 的——显然知道工程化落地的痛点是什么。这点我还是服的。

大家需要的不是一个能@的玩具，而是一个能进团队、能被治理、能协作的数字员工。

AI 工程化的未来，是团队化、治理化、协作化。

别再一个人@来@去了。

**给你的 Agent 造个工位罢。**

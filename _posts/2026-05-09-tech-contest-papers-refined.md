## 一、图形化编程：启蒙第一站

**代表工具**：Scratch / Blockly / Mixly

**考什么**：
真题涵盖从基础积木块到复杂算法。别以为"拖积木"简单——逻辑不对，拖再多也是乱麻。
核心考点大抵是这三样：
1. **循环与条件判断**：什么时候用"重复执行"，什么时候用"如果...那么"。
2. **变量与消息广播**：多角色协同时的通信逻辑。
3. **坐标与运动**：让角色精准走到指定位置，而不是瞎撞。

**避坑指南**：
很多孩子只会"照葫芦画瓢"，题目稍改就不会了。
**我的建议**：练真题时，要求孩子**口述逻辑**。能说出来，才是真懂了。

:::callout info
**适用人群**：小学 1-6 年级，零基础入门。
**备考周期**：2-4 周（每天 30 分钟）。
:::

## 二、Python 编程：从拖积木到写代码

**考什么**：
大约是最适合进阶的语言罢。
真题覆盖基础语法、数据结构、算法实现——从循环到递归，从列表到字典，横竖都要写一遍。
核心考点：
1. **字符串与列表操作**：切片、索引、常用方法。
2. **函数封装**：把重复代码变成函数，参数传递不能错。
3. **基础算法**：排序、查找、简单数学逻辑。

**避坑指南**：
孩子常卡在**缩进**和**类型转换**上。`"1" + 1` 会报错，这种细节真题最爱考。
**我的建议**：不要只看在屏幕上跑通，要让孩子**手写代码**。手写的记忆，大抵比复制粘贴深刻。

:::callout info
**适用人群**：小学 4 年级以上，有图形化编程基础。
**备考周期**：4-6 周。
:::

## 三、C 语言编程：底层到底层

**考什么**：
说实话，这一块大抵是最难的。
真题涵盖指针、内存管理、结构体——大约能把脑子从"写代码"变成"理解计算机"。
我见过许多"会写 Python"的学生，却从未见过 C 语言如此扎实的——大约是底层会让人怀疑人生罢。
核心考点：
1. **指针与数组**：内存地址的理解，越界访问的后果。
2. **结构体与链表**：数据组织的底层逻辑。
3. **文件读写**：数据的持久化。

**避坑指南**：
C 语言不允许"差不多"。少一个分号，多一个星号，程序直接崩溃。
**我的建议**：先理解内存模型，再写代码。脑子里有内存图，指针就不难。

:::callout info
**适用人群**：初中以上，有 Python 基础。
**备考周期**：8 周以上（需扎实打底）。
:::

## 四、无人机技术：飞行的代码

**考什么**：
真题涵盖飞行原理、编程控制、任务设计。
大约能把孩子从"玩无人机"变成"编程飞无人机"。
核心考点：
1. **姿态控制**：PID 算法的简化应用，如何让飞机悬停更稳。
2. **路径规划**：给定坐标，自动飞行避开障碍。
3. **传感器应用**：超声波、气压计数据的读取与处理。

**避坑指南**：
很多人以为"遥控飞得好"就能赢。大抵是误解了。
比赛考的是**编程控制**。遥控只是调试手段，代码才是得分关键。

:::callout info
**适用人群**：小学 3 年级以上。
**注意**：需配合实体无人机或高仿真模拟器练习。
:::

## 五、机器人技术：硬件的代码

**考什么**：
真题涵盖结构设计、传感器应用、编程控制。
硬件有代价，代码有代价，调试有代价。
很多人以为"买个机器人套件"就能参赛——然而翻开真题一查，才发现套件不是万能药，编程思维才是真正需要理解的。
核心考点：
1. **传感器逻辑**：巡线、避障、颜色识别的逻辑判断。
2. **电机控制**：差速转弯、PID 调速。
3. **任务策略**：如何在有限时间内完成最多任务。

**避坑指南**：
硬件调试是玄学？不，是科学。
**我的建议**：遇到问题先查代码逻辑，再查硬件接线。90% 的"硬件故障"，大抵是代码写错了。

:::callout info
**适用人群**：小学 3 年级以上。
**建议**：组队参赛，分工明确（一人写代码，一人搭硬件，一人调试）。
:::

## 六、三维创意设计：空间的代码

**考什么**：
真题涵盖三维建模、创意设计、工程思维。
大约能把孩子从"画平面图"变成"建三维模型"。
核心考点：
1. **建模能力**：熟练使用拉伸、旋转、放样等命令。
2. **工程思维**：设计的东西能不能"打印出来"？壁厚够不够？有没有悬空？
3. **创意表达**：设计说明是否清晰，结构是否合理。

**避坑指南**：
设计不是画画，是工程。
很多作品"看着好看"，但一打印就散架。真题常考**可制造性分析**。
**我的建议**：建模时多问一句："这玩意儿现实中能造出来吗？"

:::callout info
**适用人群**：小学 4 年级以上。
**工具推荐**：Tinkercad（入门）、Blender/Fusion360（进阶）。
:::

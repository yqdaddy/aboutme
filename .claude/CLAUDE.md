# 码孖AI 技术博客

## 项目概述

Jekyll 静态站点生成器博客，部署于 GitHub Pages。

## 技术栈

- **框架**: Jekyll 4.3
- **语言**: Ruby, Markdown, HTML, CSS
- **部署**: GitHub Pages
- **主题**: minimal (remote_theme)
- **插件**: jekyll-feed, jekyll-seo-tag, jekyll-sitemap, jekyll-paginate

## 目录结构

```
_posts/        # 博客文章
_layouts/      # 布局模板
_includes/     # 可复用组件
assets/        # CSS, JS, 图标
```

使用 `/dev-am "任务描述"` 启动团队协调。

## 使用指南

### 内容创作
- 新文章：`@dev-am-content-writer "写一篇关于...的文章"`
- SEO 优化：`@dev-am-seo-specialist "优化这篇文章的 SEO"`

### 前端开发
- UI 修改：`@dev-am-frontend-developer "修改博客主题..."`

### 质量验证
- 验证完成：`@dev-am-reality-checker "验证这个功能是否真正完成"`
